# System Design

System design interviews, capacity planning, trade-offs

## What's Included

### Agents
- **System Designer** - Specialized agent for System design interviews, capacity planning, trade-offs

### Commands
- `/system-design` - Quick-access command for system-design workflows

### Skills
- **System Design Patterns** - Pattern library and knowledge base for system-design

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/system-design analyze

# Use the command with specific input
/system-design generate --context "your project"

# Reference patterns from the skill
"Apply system-design-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for system-design
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
