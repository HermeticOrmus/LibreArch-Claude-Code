# Cqrs Event Sourcing

CQRS, event sourcing, projections, event stores

## What's Included

### Agents
- **Cqrs Architect** - Specialized agent for CQRS, event sourcing, projections, event stores

### Commands
- `/cqrs` - Quick-access command for cqrs-event-sourcing workflows

### Skills
- **Cqrs Patterns** - Pattern library and knowledge base for cqrs-event-sourcing

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/cqrs analyze

# Use the command with specific input
/cqrs generate --context "your project"

# Reference patterns from the skill
"Apply cqrs-patterns patterns to this implementation"
```

- Follow established conventions for cqrs-event-sourcing
