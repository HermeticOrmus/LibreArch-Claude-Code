# Clean Architecture

Clean/onion architecture, dependency rule, use cases

## What's Included

### Agents
- **Clean Arch Engineer** - Specialized agent for Clean/onion architecture, dependency rule, use cases

### Commands
- `/clean-arch` - Quick-access command for clean-architecture workflows

### Skills
- **Clean Arch Patterns** - Pattern library and knowledge base for clean-architecture

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/clean-arch analyze

# Use the command with specific input
/clean-arch generate --context "your project"

# Reference patterns from the skill
"Apply clean-arch-patterns patterns to this implementation"
```

## Key Patterns

- Follow established conventions for clean-architecture
- Validate inputs before processing
- Document decisions and rationale
- Test outputs against requirements
- Iterate based on feedback
