# Saga Patterns

Saga orchestration, choreography, compensation

## What's Included

### Agents
- **Saga Architect** - Specialized agent for Saga orchestration, choreography, compensation

### Commands
- `/saga` - Quick-access command for saga-patterns workflows

### Skills
- **Saga Patterns** - Pattern library and knowledge base for saga-patterns

## Quick Start

1. Copy this plugin to your Claude Code plugins directory
2. Use the agent for guided, multi-step workflows
3. Use the command for quick, targeted operations
4. Reference the skill for patterns and best practices

## Usage Examples

```
# Use the command directly
/saga analyze

# Use the command with specific input
/saga generate --context "your project"

# Reference patterns from the skill
"Apply saga-patterns patterns to this implementation"
```
