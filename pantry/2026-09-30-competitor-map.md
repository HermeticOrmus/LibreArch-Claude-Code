# Competitor map: LibreArch-Claude-Code

Run of 2026-09-30. Star counts come from the GitHub API (`gh api repos/<owner>/<repo>`) in this run; feature claims come from each project's README, catalog or article as fetched in this run. A blank or `?` cell means the source did not say.

## Product

- Name: LibreArch-Claude-Code, release v1.0.0, marketplace `libre-arch`
- Flagship: `domain-driven-design` (agent `ddd-strategist`, command `/ddd` with modes `model`, `map-contexts`, `validate`, `generate`, skill `domain-driven-design`)
- Our surfaces: 21 plugins in `.claude-plugin/marketplace.json`: 20 domain plugins (20 agents, 20 commands, 20 skills) plus `libre-arch-hooks` (SessionStart architecture summary, a PreToolUse `ask` before Read, Edit, Write or MultiEdit on `.env`, key and secrets files, and a PostToolUse dependency-direction scan of edited source files). The original root `hooks/` scripts are kept for reference. Install with `/plugin marketplace add HermeticOrmus/LibreArch-Claude-Code` or `./setup.sh`. CI (`.github/workflows/validate.yml`) validates the marketplace and every plugin, then installs all of them into a clean config.
